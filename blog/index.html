My Oasis Infobyte Web Development Internship - Level 1 Tasks

Mahi Gupta - October 2026

This post documents my Level 1 task submissions for the Oasis Infobyte Web Development and Designing Internship (oasisinfobyte.com), part of the AICTE OIB-SIP October 2026 P1 cohort. For the Web Development and Designing track I chose Level 1, which consists of three tasks.

Task 1 - Landing Page

A responsive marketing page for a fictional artisan tea brand, with a hero section, feature cards, product grid and contact footer, built with semantic HTML and CSS.

Task 2 - Personal Portfolio

A responsive single-page portfolio with about, technologies and projects sections, built with HTML and CSS.

Task 3 - Temperature Converter

An interactive converter between Celsius, Fahrenheit and Kelvin with input validation and absolute-zero handling, built with HTML, CSS and vanilla JavaScript.

All three projects are open source on GitHub and deployed on GitHub Pages. Each task folder includes a README and a demo video walkthrough.

Written for the Oasis Infobyte Web Development and Designing Internship (Level 1).
